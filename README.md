# Portfolio CMS

A full-stack Portfolio Content Management System built with Node.js, Express.js, MySQL and EJS.

## 🚀 Live Demo

**Website:**  
https://portfolio-cms-2-oohr.onrender.com/

**Admin Panel:**  
https://portfolio-cms-2-oohr.onrender.com/admin

## ✨ Key Features

- Dynamic portfolio website
- Admin authentication
- Admin dashboard
- CRUD content management
- Manage Home, About, Services, Projects, Testimonials and Blog
- Image upload functionality
- MySQL database integration
- Responsive UI

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS
- MySQL
- HTML
- CSS
- JavaScript
- Git & GitHub
- Render
- Clever Cloud

## 📌 Project Highlights

- Built a complete Portfolio CMS from scratch
- Implemented admin-side content management
- Integrated Node.js backend with MySQL
- Deployed the application using Render and Clever Cloud
